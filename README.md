PiCad:

PiCad is an open source mini arcade machine with 2 custom games based on the Raspberry Pi 4B board. It can also be used with RetroPi but the controllers may not work. One game is an adventure game where you play with up to 4 friends and you solve puzzles together. The other you must have atleast 2 people (still at most 4 people) and your on a brawl with each other. 

It has a 7" touchscreen display with it being able to be connected via either of the two micro-HDMI ports to a TV or external monitor. 

The 4 controllers are powered by USB-C 

Software:
OS: Either a custom OS or Raspberry Pi OS (Lite)
Game engine: Python + Pygame
Controller firmware: Arduino / CircuitPython
Boot behavior: auto-launches into the game menu upon start
